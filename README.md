## لوحة التحكم (للأدمن فقط) — `/admin` أو `/dashboard`
| التبويب | بيعمل إيه |
|---|---|
| 📊 نظرة عامة | المبيعات وعدد الطلبات والعملاء، رسم آخر 7 أيام، الأكثر مبيعًا |
| 📦 الطلبات | بحث وفلترة، تغيير حالة الطلب، تفاصيل العميل وحالة إرسال الإيميلات، حذف |
| 🛍️ المنتجات | إضافة وتعديل وحذف المنتجات (الاسم، السعر، المجسم 3D، الألوان، المميزات) بمعاينة حيّة |
| 👥 العملاء | بحث، بيانات كل عميل وطلباته، أزرار إيميل/اتصال/واتساب |
| ⭐ التقييمات | كل التقييمات مع حذف أي تقييم |
| ⚙️ الإعدادات | اختبار ربط EmailJS، الشحن، رقم واتساب، الكوبونات، ونشر التعديلات للعملاء |

## المفضلة والمقارنة
- ♡ على أي منتج لإضافته للمفضلة (صفحة `/favorites`، وعدّاد في النافبار).
- ⚖ على 2-3 منتجات ثم "قارني الآن" لصفحة `/compare` فيها مجسمات جنب بعض وشارات "الأرخص" و"الأعلى تقييمًا".
- محفوظين في `localStorage`.

## التقييمات والتعليقات
- في صفحة كل منتج: متوسط التقييم وتوزيع النجوم وكل التعليقات.
- العميل المسجل يقدر يقيّم (نجوم + تعليق)، وتقييم واحد لكل منتج بيتعدّل لو قيّم تاني. شارة "اشترت المنتج" بتظهر لو عنده طلب فيه المنتج.
- العميل يحذف تقييمه هو، والأدمن يحذف أي تقييم.
- محفوظة في `localStorage`.

## مجسم الحقيبة
نوع جديد `bag` في `ProductModel.jsx`، ومنتج `VOYAGE BAG` وقسم "أزياء". لو بتشغّلي المشروع من قبل كده، اضغطي "استرجاع الأصلية" في تبويب المنتجات علشان يظهر.

## إدارة المنتجات (للأدمن)
من لوحة التحكم ← تبويب **المنتجات**:
- إضافة منتج جديد وتعديل أي منتج وحذفه، مع معاينة 3D حيّة أثناء التعديل.
- اختيار شكل المجسم (سماعة، ساعة، أباجورة، سماعة كروية، مزهرية) وتحديد الألوان ولون التوهج بالـ color picker.
- التعديلات بتظهر فورًا في المتجر، وبتتحفظ في `localStorage`.
- زر "استرجاع الأصلية" بيرجّع المنتجات الافتراضية من `src/data/products.js`.
- لإضافة **شكل مجسم جديد** (مش بس منتج): ضيفيه في `ProductModel.jsx` وفي `modelTypes` داخل `data/products.js`.

## إعداد EmailJS (رسالة للعميل + رسالة للأدمن)
1. اعملي حساب على https://www.emailjs.com
2. **Email Services** → Add New Service (Gmail مثلًا) وخدي `Service ID`.
3. **Account → General** وخدي `Public Key`.
4. اعملي **قالبين (Templates)**، وفي كل واحد خلي حقل **To Email** = `{{to_email}}`:
   - قالب للعميل (مثلًا: تأكيد الطلب)
   - قالب للأدمن (مثلًا: طلب جديد)
5. حطي القيم الأربعة في `src/config/emailjs.js` (`publicKey` و`serviceId` و`customerTemplateId` و`adminTemplateId`).
   إيميل الأدمن اللي بتوصله إشعارات الطلبات هو أول إيميل في `src/config/admin.js`.
6. **اختبري:** من لوحة التحكم ← ⚙️ الإعدادات ← «اختبار رسالة الأدمن» و«اختبار رسالة العميل».
   لو فشل، الرسالة بتقولك السبب (مفتاح غلط، قالب مش موجود…).

> **ليه المفاتيح في الكود؟** لأن الرسالة بتتبعت من متصفح **العميل** وقت ما يأكد الطلب، فلازم المفاتيح تكون جوه الموقع المنشور.
> الـ Public Key مصمم أصلًا يكون ظاهر في المتصفح. خطة EmailJS المجانية فيها حد شهري للرسائل (شوفي موقعهم).

### المتغيرات المتاحة داخل القوالب
| المتغير | المعنى |
|---|---|
| `{{to_name}}` / `{{to_email}}` | اسم وإيميل المستلم |
| `{{order_id}}` / `{{order_date}}` | رقم الطلب وتاريخه |
| `{{{order_details_html}}}` | المنتجات (HTML) — بثلاث أقواس |
| `{{order_details_text}}` | المنتجات (نص عادي) |
| `{{subtotal}}` `{{discount}}` `{{shipping}}` `{{total}}` | الحسابات |
| `{{delivery_date}}` / `{{delivery_window}}` | موعد الاستلام ووقته |
| `{{customer_name}}` `{{customer_email}}` `{{customer_phone}}` `{{customer_address}}` | بيانات العميل |

مثال لقالب العميل:
```
أهلًا {{to_name}}،
تم تسجيل طلبك رقم {{order_id}} بنجاح ✅

{{{order_details_html}}}

الإجمالي: {{total}}
موعد الاستلام: {{delivery_date}} ({{delivery_window}})
```
مثال لقالب الأدمن:
```
طلب جديد {{order_id}} من {{customer_name}}
الموبايل: {{customer_phone}} | العنوان: {{customer_address}}

{{{order_details_html}}}

الإجمالي: {{total}}
```
> لو ظهرت علامات HTML في الرسالة، استخدمي `{{order_details_text}}` بدل `{{{order_details_html}}}`.

## نشر تعديلات الأدمن للعملاء
كل تعديلاتك من لوحة التحكم (منتجات، كوبونات، شحن) بتتحفظ في متصفحك أنتِ. علشان توصل للعملاء:
لوحة التحكم ← ⚙️ الإعدادات ← **تحميل products.js** ← استبدلي بيه `src/data/products.js` ← ارفعي المشروع من جديد.

## هيكل المشروع
```
src/
  config/ (admin.js, emailjs.js)   ← إيميل الأدمن وإعدادات EmailJS
  services/email.js                ← إرسال الرسالتين + اختبار الربط
  utils/catalogExport.js           ← توليد ملف products.js المحدّث
  context/ (Auth, Orders, Products, Settings, Wish, Reviews, Cart)
  components/ (Navbar, RequireAuth, CartDrawer, ProductCard, ProductForm, Reviews, Scene3D, ProductModel)
  components/admin/ (CustomersTab, ReviewsTab, SettingsTab)
  pages/ (Home, Shop, ProductPage, Login, Checkout, OrderSuccess, MyOrders, Favorites, Compare, Admin)
```

## حدود المشروع (بدون باك اند)
الحسابات والطلبات والتقييمات محفوظة في `localStorage` كل متصفح لوحده، فعشان كده:
- **الأدمن بيشوف في الداشبورد الطلبات اللي اتعملت من نفس المتصفح بس.** طلبات العملاء على أجهزتهم بتوصلك **بالإيميل** (EmailJS) مش في الداشبورد.
- تحديد الأدمن بالإيميل بيحمي الواجهة بس، مش حماية حقيقية: أي حد يقدر يسجل بإيميل الأدمن في متصفحه هو ويشوف داشبورد فاضية خاصة بيه (مفيش بيانات حقيقية بتتسرب لأنها مش على سيرفر).
- أي حد بيفتح DevTools يقدر يعدّل بيانات متصفحه.

لو عايزة الداشبورد يعرض **كل** الطلبات والعملاء من كل الأجهزة، والأدمن يتحقق منه بشكل حقيقي، لازم قاعدة بيانات
خارجية (مثلًا Firebase أو Supabase)، وده ممكن يتضاف من غير ما تكتبي سيرفر بنفسك.
